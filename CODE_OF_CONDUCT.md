# Code of Conduct

Iguazu is an LF Decentralized Trust project. All participants are expected to
follow the [LF Decentralized Trust Code of Conduct](https://lf-decentralized-trust.github.io/governance/governing-documents/code-of-conduct/).

Incidents may be reported to the project maintainers listed in
[MAINTAINERS.md](MAINTAINERS.md) or to the Linux Foundation contacts listed in the
Code of Conduct.
