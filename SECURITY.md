# Security Policy

Iguazu, an LF Decentralized Trust project, handles security vulnerabilities according
to the [Iguazu Security Policy](https://github.com/LFDT-Iguazu/governance/blob/main/SECURITY.md),
which also lists the security team.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.
Use one of the following channels instead:

- Open a [GitHub security vulnerability report](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability):
  a draft security advisory on the "Security" tab of this repository.
- Email the [LF Decentralized Trust security list](mailto:security@lists.lfdecentralizedtrust.org)
  with the name of the project/repository, a description of the issue, the steps to
  reproduce it, the affected versions, and, if known, mitigations.
